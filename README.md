# Lounge Market Library

Market research for **Lounge at the Edge of the Universe**, a third space opening in Bhubaneswar.
Every cafe in the city, read through one line: *people want a piece of themselves in real life.*

Live site: https://waschin.github.io/lounge-market-library/

- `index.html` is the whole site: every cafe, menu, review summary and insight is embedded in it.
- Updated from the private Claude library whenever a new cafe is logged.
